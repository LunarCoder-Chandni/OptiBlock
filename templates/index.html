How the engine reasons about a request

Every request gets a priority score (asset criticality, deadline urgency, and a safety-critical bonus) computed by the Flask backend. Compatible requests in the same section are checked for fusion into one combined possession, and each surviving request is placed in the lowest traffic-cost window — read against the corridor's actual train timetable — that still respects its deadline. Open any block in the AI Schedule tab to see this reasoning applied to that block.
